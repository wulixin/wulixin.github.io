## 技术栈
- D3.js v7 (CDN) - 力导向网络图
- 原生JS - 交互逻辑、中英文切换
- Canvas API - 背景粒子动画
- 纯CSS - 深色主题、渐变效果

## 通用设计模板
- D3力导向网络图谱 + 技能卡片 + 包列表三视图
- 中英文双语切换
- 全局搜索过滤
- 深色主题 + 背景粒子动画
- 点击分类弹窗显示完整包列表
- 响应式布局
- 可复用于任意CRAN Task View
- 居中大字标题(official.html起)：hero-title区，38px渐变大字+副标题描述
