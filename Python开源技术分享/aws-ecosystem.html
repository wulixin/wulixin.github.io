📜 发展历程

从 SDK 开源到 AI Agent 平台

2012–2014
发布 AWS SDK for Java/PHP/Ruby/Node.js，奠定多语言 SDK 基础；开源 aws-cli 统一命令行工具
2015–2016
开源 s2n-tls 加密库（形式化验证的 TLS 实现）；发布 aws-sdk-go，进入 Go 生态；开源 Amazon Kinesis 客户端库
2017–2018
发布 AWS CDK（TypeScript IaC 框架）；开源 Firecracker 微虚拟机；推出 SageMaker 系列工具（Python SDK、容器、训练/推理工具包）
2019–2020
开源 Karpenter K8s 自动扩缩器；发布 aws-sdk-pandas；推出 EKS Anywhere 混合云方案；开源 Deep Learning Containers
2021–2022
发布 Lambda Web Adapter（Rust 高性能适配）；开源 s2n-quic（QUIC 协议实现）；推出 aws-lc-rs（Rust 密码学库）；SAM CLI 持续演进
2023–2024
发布 Amazon Q Developer CLI（AI 终端助手）；推出 Bedrock AgentCore SDK（Agent 生产化）；开源 HyperPod 训练集群管理；发布 FMEval 模型评估库
2025–至今
开源 Nova Act（AI 浏览器自动化）；发布 MCP Proxy for AWS（AI 工具链集成）；AgentCore CLI 重构；Lambda Durable Functions SDK 多语言发布
